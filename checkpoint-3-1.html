1. List three reasons to use CSS on a web page.

The site is much easier to maintain. This helps to keep the structure and unity. Another reason to use CSS on a web page is to create a consistent appearance throughout the whole page. Finally, styles can be stored in a separate document and associated with the web page.

2. Why configure both text color and background color?

We want to do that to make sure that we keep the contrast high. By configuring both the text color and the background color, we can make sure that the contrast is high enough so that it is easy to read. It also helps us to create the website in a consistent and unified manner.

3. Describe one advantage to using embedded styles instead of inline styles.

One advantage of embedded styles is that you can apply the same style to multiple elements on a webpage without having to write the style for each element individually.

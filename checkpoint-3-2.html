1. Describe a reason to use embedded styles. Explain where embedded styles are placed on a web page.

Embedded styles are configured in the header section of a web page. Embedded styles are very useful when you want to apply a style to many different elements on the webpage.

2. Describe a reason to use external styles. Explain where external styles are placed and how web pages indicate they are using external styles.

External styles are perfect when you want to the same styles on multiple different web pages. CSS style rules are contained in a text file separate from the HTML documents. A webpage uses a link element in the head section to connect to the external CSS file.
